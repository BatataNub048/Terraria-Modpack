# Rev8 Crafting Progression

The published source is v0.8.0, verified through [T1-C3](t1-c3.md). [T1-D1](t1-d1.md) is an audit only. T1-D2 and v0.9.0 have no verified local source or test report for this publication.

Build with tModLoader 2026.9.3.1. Copy the complete [Rev8CraftingProgression source folder](../../rev8/source/Rev8CraftingProgression) into tModLoader’s ModSources directory and use Workshop > Develop Mods > Build. Obtain the required references in build.txt from their authorized sources. Match the audited dependency versions and optional integration load order using the [71-mod profile lock](../../rev8/profiles/TodosRecuperados-Titanico-Desempenho.lock.json). The source uses base-game texture references.

The dependency snapshot retains the recipe records referenced by the saved graphs. The gameplay reports summarize run outcomes and identify local evidence from the disposable lab.
