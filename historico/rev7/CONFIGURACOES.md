# Configurações e desempenho

O preset é aplicado pelo instalador aos arquivos de ModConfigs; preserve-o igual no host e clientes para as opções de servidor. As opções gráficas locais podem variar por PC. Não copiar o config.json completo de outro computador, pois inclui resolução e outros dados específicos.

| Configuração aplicada | Valor / propósito |
|---|---|
| Calamity Afterimages | false: reduz efeitos de pós-imagem |
| Calamity ParticleLimit | 1000: limite conservador inicial, sem benchmark prometido |
| Calamity ScreenshakePower | 0.5: conforto visual; não é otimização de FPS |
| Calamity BossHealthBoost | 0: sem multiplicação extra |
| Fargo Souls PerformanceMode | true |
| Old DLC EnableCalamity / EnableThorium | true |
| Old DLC AddFargosDLCRecipeChangesWhenDisabled | false: não importar mudanças do DLC oficial ausente |
| Ragnarok item_deduplication_mode | 1 |
| Ragnarok genericweaponchanges | true |
| BardHealer generalItemBalanceChanges / rogueThrowerMerge | false: Ragnarok fica responsável por essas mudanças |
| BardHealer showItemChanges | true |
| Magic Storage recursionCraftingDepth | 0: evitar crafting recursivo pesado no início |
| Magic Storage showAllRecipes / itemDataDebug | false |
| LuiAFK potionsEnable / vanillaPotionsEnable | false / Disabled: evita sobreposição das poções ilimitadas com Fargo |
| Fargo x Shop Expander | Mutant e Squirrel ativados |
| Angler Shop | Moeda customizada desligada; multiplicador de ouro 2 |

O desempenho depende principalmente da cena, CPU, resolução, projéteis e número de jogadores. Mais conteúdo não garante FPS igual ao pack menor. Nenhum valor de ganho foi medido. Comece com zoom normal, reduza efeitos/qualidade no menu gráfico e teste a mesma cena; evite zoom muito afastado. Limite invocações/eventos simultâneos no ensaio inicial. Não instale “otimizadores” por cima para tentar esconder um erro de mod.

Shared World Map: começar com envio manual e evitar compartilhamento automático frequente. Um mapa Large tem custo de transferência; o tempo depende da conexão. Auto Trash: iniciar sem regras de descarte até conhecer os itens novos. Não usar seeds especiais/opções experimentais do Fargo Seeds na primeira geração.

Calamity Fables oferece opções para conteúdo duplicado com Calamity. Confira no cliente antes de definir a campanha; não foram gravadas chaves de configuração não verificadas. Wrath of the Machines altera Exo Mechs: teste essa luta em cópia antes de depender dela para progressão. Extras/Pandora também não foi exercitado integralmente.

More Accessories não é instalado. Se uma futura revisão o reintroduzir após corrigir os relatos, o contorno documentado pelo autor para acessórios Calamity é EnableLoadoutSupport=false, com 3 slots inicialmente. Retire acessórios extras antes de mudar loadouts/quantidade em personagem existente. Isso NÃO comprova correção dos relatos de lag/tela de personagem.

Eternity, Revengeance, Death e outras dificuldades não são habilitados pelo instalador. Confira no mundo novo antes de jogar. Não combine modificadores de IA na primeira validação multiplayer.
